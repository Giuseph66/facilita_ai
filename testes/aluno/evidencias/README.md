# Evidências do percurso de aluno

Não há capturas de tela da sessão do aluno salvas como arquivos recuperáveis. As imagens foram exibidas temporariamente pelo navegador/CUA e não foram persistidas. Nenhuma imagem foi recriada ou atribuída falsamente como evidência.

As imagens locais vistas durante a coleta pertencem à jornada docente (agora em `testes/docente/evidencias/`) ou são fixture (`testes/fixtures/fotossintese-qa.png`); não foram copiadas para cá como se fossem capturas do aluno. A pasta antiga de imagens docentes foi substituída após conferir que as seis cópias eram idênticas.

Consulte [observações textuais](observacoes-textuais.md) para os estados visíveis e [métricas móveis](metricas-mobile.json) para os valores de layout.
